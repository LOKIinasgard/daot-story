# DAOT: Path of the Attack

**Аддон** для Danny's AoT (Minecraft 1.21.1 Fabric)

Сюжетная кампания в духе 1 сезона Attack on Titan.

## Зависимости
- Minecraft 1.21.1
- Fabric Loader
- Fabric API
- **Danny's AoT**

## Что есть в v0.3.0

### Диалоги
- Полноценные диалоги с выбором (пиши цифру в чат)
- Микаса, Армин, Леви

### NPC
- Микаса, Армин, Леви
- Ханджи, Эрвин, Жан, Саша, Конни

### Квесты
- «Первый друг» (поговорить с Армином)
- «Та, что всегда рядом» (поговорить с Микасой)
- «Беги к стене Розы»
- «Капитан» (встретить Леви)

Стартовые квесты выдаются при первом входе.

### Событие «Падение стены»
Команда (нужны права оператора):
```
/daotstory breach
```
- Темнота + тошнота + замедление
- Эпичные сообщения
- Звуки взрыва и грома
- Переход на следующий этап сюжета
- Выдаётся квест «Беги к стене Розы»

Сброс события:
```
/daotstory resetbreach
```

## Как тестировать
1. Зайди в мир
2. Получишь стартовые квесты
3. Заспавни NPC (пока через команды summon, модели будут позже)
4. Поговори с ними (ПКМ)
5. Напиши `/daotstory breach` чтобы запустить падение стены
