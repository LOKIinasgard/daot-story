# AOT Story (Fabric 1.21.1)

Сюжет первого сезона «Атаки Титанов»: каждый этап открывается только после диалога с NPC.

## Сборка
Пуш в GitHub -> вкладка **Actions** -> job `build` -> артефакт `aotstory` (jar).

## Проверка в игре
1. Новый мир: рядом появляется Ханнес, мир «заморожен» (нет смены дня/ночи, спавна мобов, погоды).
2. ПКМ по Ханнесу -> диалог. После последней кнопки: титул «Год 845», разморозка мира, появляется Эрен.
3. ПКМ по Эрену -> второй диалог.

Отладка (оператор): `/aotstory flags | set <флаг> | clear <флаг> | reset | npc <id>`.

## Как добавлять сюжет
- Диалог: `src/main/resources/data/aotstory/dialogues/<имя>.json` (`/reload` подхватывает без перезапуска).
- Звено цепочки: новый флаг в `Flags.java` + `StoryEvents.on(флаг, обработчик)`.
- Персонаж: имя в `Npcs.NAMES`, скин `assets/aotstory/textures/entity/npc/<id>.png`.
