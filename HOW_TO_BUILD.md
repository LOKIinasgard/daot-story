# Как собрать и установить мод

## Вариант 1 — Быстрый (рекомендую)

1. Скачай официальный Fabric template:
   https://fabricmc.net/develop/

2. Создай новый проект на 1.21.1

3. Замени содержимое `src/main/java` и `src/main/resources` на файлы из этой папки `daot-story`

4. В `build.gradle` и `gradle.properties` можешь взять то, что я уже положил

5. В IntelliJ / VS Code:
   - Открой проект
   - Запусти `gradle genSources`
   - Запусти `gradle build`

6. Готовый `.jar` появится в `build/libs/daot-story-0.3.0.jar`

7. Кидай его в `mods` вместе с Danny's AoT

## Важно
- Мод **требует** Danny's AoT
- Без него Колоссальный титан не заспавнится
- NPC пока без моделей (используют стандартную модель игрока/моба) — модели добавим позже

## Команды в игре
```
/daotstory breach          — запустить падение стены + спавн Колоссального
/daotstory resetbreach     — сбросить событие (для тестов)
```
